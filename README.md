# Construcció de Catapultes amb LEGO

Projecte desenvolupat per a la Setmana STEAM, concretament per a la jornada dedicada a la Tecnologia.

L’activitat està pensada per a alumnat de Cicle Mitjà i Cicle Superior de Primària i treballa el procés tecnològic mitjançant el disseny, construcció, prova i millora d’una catapulta funcional construïda amb peces LEGO.

---

# Objectius del projecte

- Aplicar el procés tecnològic complet.
- Desenvolupar estratègies de resolució de problemes.
- Experimentar amb estructures i mecanismes.
- Treballar el pensament computacional sense necessitat de programació.
- Fomentar el treball cooperatiu i la comunicació.
- Potenciar la creativitat i la cultura maker.

---

# Reptes per nivells

## Cicle Mitjà (3r i 4t)
### “La catapulta més llunyana”

Objectiu:
Construir una catapulta capaç de llençar el projectil el més lluny possible.

Es prioritza:
- exploració,
- manipulació,
- relació causa-efecte,
- millora del prototip.

---

## Cicle Superior (5è i 6è)
### “La catapulta de precisió”

Objectiu:
Construir una catapulta capaç d’encertar objectius amb el màxim control i precisió.

Es prioritza:
- optimització,
- estabilitat,
- calibratge,
- anàlisi de resultats.

---

# Procés tecnològic

L’activitat segueix les fases bàsiques del procés tecnològic:

1. Pensar i planificar
2. Construir
3. Provar
4. Detectar problemes
5. Millorar
6. Presentar el prototip final

---

# Estructura del taller

Durada aproximada: 1 hora

- Presentació del repte
- Disseny inicial
- Construcció del prototip
- Fase de proves
- Millora del disseny
- Reptes finals
- Presentació dels equips
